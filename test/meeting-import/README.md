# 회의록 import 테스트

Pi를 재시작한 뒤 프로젝트 루트에서 다음 명령을 실행합니다. 파일 경로 입력 UI가 표시되면 회의 텍스트 파일 경로를 입력합니다.

```text
/codystat
```

## 확인할 내용

- 회의록이 지정된 Markdown 구조로 생성되는가
- 결정되지 않은 PDF 내보내기가 액션 아이템으로 잘못 생성되지 않는가
- 담당자와 기한이 원문에 있는 액션 아이템에만 포함되는가
- 티켓 후보가 실제 작업인 모바일 댓글 지연 로딩만 포함하는가
- 티켓 번호를 원문에 없는데 추측하지 않는가

생성 결과는 우선 대화창에서 검토합니다. 검증 전에는 Supabase나 Plane에 저장하지 않습니다.
