# 초기 구현 순서

## 1단계. 기본 구조 확정
- 워크스페이스 1개로 시작
- 팀 구조 정의
- 권한 역할 정의
- 티켓 상태 값 정의
- 회의록 문서 구조 정의

## 2단계. Plane 기본 세팅
- 팀원 초대
- 역할 부여
- Work Items 활성화
- Pages / Wiki 사용 여부 정리
- 필요한 상태값만 남기기

## 3단계. 티켓 접수 흐름
- 단일 접수함 만들기
- Google Form 또는 수기 입력 연결
- 새 제보가 자동으로 티켓이 되게 하기
- 티켓에 유형/우선순위/팀 정보를 붙이기

## 4단계. 회의록 흐름
- 전체 회의록 페이지 구조 만들기
- 댓글 허용 방식 정하기
- 관련 티켓 링크 규칙 만들기
- 액션 아이템 포맷 통일

## 5단계. 조직도 화면
- 팀 트리 시각화
- 팀별 멤버 표시
- 팀별 티켓 수 표시
- 팀 수정 UI 추가

## 6단계. Astro 포털 연결
- 홈 대시보드
- 조직도
- 티켓 접수함
- 티켓 상세
- 회의록 목록/상세

## 7단계. 자동화 확장
- 폼 → 티켓 자동 생성
- 기본 분류 자동화
- 알림 연결
- 반복 업무 템플릿화

## 8단계. 운영 안정화
- 권한 점검
- 팀 중복/누락 점검
- 상태값 정리
- 회의록/티켓 연결 품질 점검
- 불필요한 Plane 기능 비활성화
