# 9월 첫째 주 제품 운영 회의

> 회의일: 2025년 9월 5일

## 한눈에 보기

모바일 티켓 상세 화면 지연의 원인은 티켓 목록 조회 시 댓글을 모두 불러오는 방식으로 확인되었다. 댓글을 상세 화면에서만 지연 로딩하도록 수정하고, 9월 5일까지 개발한 뒤 9월 8일 운영 검증을 진행한다. PDF 내보내기는 이번 주에 구현하지 않고 다음 회의에서 범위를 논의한다.

## 핵심 결정

1. 티켓 상세 화면에서 댓글을 지연 로딩한다.
2. 개발 완료 목표일은 2025년 9월 5일이다.
3. 운영 검증일은 2025년 9월 8일이다.
4. PDF 내보내기는 이번 주에 구현하지 않고 다음 회의에서 범위를 논의한다.

## 액션 아이템

- [ ] 티켓 목록 조회 시 댓글을 불러오지 않고, 상세 화면에서만 댓글을 지연 로딩하도록 수정한다 — 이지은, 2025년 9월 5일까지
- [ ] 댓글 지연 로딩 수정 사항을 검증한다 — 박준호, 2025년 9월 8일
- [ ] PDF 내보내기 범위를 논의한다 — 다음 회의

## 논의 요약

### 모바일 티켓 상세 화면 성능

모바일 티켓 상세 화면이 느리다는 제보가 세 건 접수되었다. 네트워크 요청 확인 결과, 티켓 목록 조회 시 모든 댓글을 한 번에 가져오는 문제가 확인되었다.

### PDF 내보내기

회의록을 PDF로 공유해달라는 요청이 있었다. PDF 내보내기는 이번 주에 구현하지 않고 다음 회의에서 범위를 정하기로 했다.

- PDF 내보내기 범위를 논의할 다음 회의 일정은 확인이 필요하다.
