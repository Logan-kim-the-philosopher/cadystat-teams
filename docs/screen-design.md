# 화면 설계

## 1. 홈 대시보드
### 목적
- 전체 상태를 한눈에 봅니다.

### 주요 영역
- 오늘 들어온 제보
- 진행 중 티켓
- 보류 티켓
- 최근 회의록
- 팀별 티켓 수

### 핵심 컴포넌트
- KPI 카드
- 최근 활동 목록
- 팀 현황 위젯
- 빠른 이동 버튼

---

## 2. 조직도
### 목적
- 어떤 팀이 있고, 누가 속해 있는지 보여줍니다.

### 주요 영역
- 팀 트리 / 계층 구조
- 팀 카드
- 팀원 목록
- 팀별 담당 티켓 수
- 팀 수정 버튼

### 핵심 컴포넌트
- 트리 뷰
- 팀 카드
- 멤버 아바타 목록
- 편집 패널

---

## 3. 티켓 접수함
### 목적
- 오류/기능 제보를 단일 창구로 모읍니다.

### 주요 영역
- 신규 접수 티켓 목록
- 필터: 상태 / 우선순위 / 유형
- 팀이 가져가기 버튼
- 담당 팀 미지정 티켓 강조

### 핵심 컴포넌트
- 표 또는 카드 목록
- 상태 배지
- 우선순위 배지
- 할당 버튼
- 검색창

---

## 4. 티켓 상세
### 목적
- 처리 과정과 책임 주체를 명확히 보여줍니다.

### 주요 영역
- 제목 / 설명
- 현재 상태
- 담당 팀 / 담당자
- 이관 이력 타임라인
- 댓글 / 처리 메모
- 관련 회의록

### 핵심 컴포넌트
- 상태 패널
- 타임라인
- 댓글 스레드
- 메타데이터 패널
- 관련 문서 링크

---

## 5. 전체 회의록 목록
### 목적
- 전체 회의 기록을 모아봅니다.

### 주요 영역
- 날짜순 회의록 목록
- 검색 / 필터
- 관련 티켓 수
- 댓글 수

### 핵심 컴포넌트
- 목록
- 날짜 구분선
- 태그/라벨
- 검색창

---

## 6. 전체 회의록 상세
### 목적
- 회의 내용, 결정사항, 연결 티켓, 댓글을 한 페이지에서 봅니다.

### 주요 영역
- 회의 일시
- 참석자
- 안건
- 논의 내용
- 결정사항
- 액션 아이템
- 연결 티켓
- 댓글

### 핵심 컴포넌트
- 문서 뷰어
- 참석자 칩
- 연결 티켓 목록
- 댓글 영역
- 상단 요약 카드

---

## 7. 공통 UX 원칙
- 목록은 빠르게 훑을 수 있어야 합니다.
- 상태/담당팀/우선순위는 항상 보여줍니다.
- 조직도와 티켓, 회의록은 서로 연결되어야 합니다.
- 댓글은 회의록과 티켓 모두에서 자연스럽게 이어져야 합니다.
